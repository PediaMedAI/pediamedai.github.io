{{- /* Render an . Raster theme assets get resized to {width}x and converted to WebP at the configured quality. When the source is at least 2× the target width, a 2x source is also emitted via srcset so retina displays don't render a soft image. SVGs pass through as a single . External / static paths are passed through relURL so callers don't have to branch at the call site. Args: src (required) e.g. "img/workshops/cv4chl_bg.jpg" or "/images/legacy.jpg" alt (required) width (optional) resize target width for raster (default 800); also emitted as an HTML width attribute on SVG and fallback paths so the browser can reserve layout space and avoid CLS. height (optional) HTML height attribute (only used when not derivable) quality (optional) WebP quality (default 82; logos can use ~70) loading (optional) default "lazy" — overridden to "eager" when priority is set priority (optional) bool — set true for the LCP image on a page; emits loading="eager" + fetchpriority="high" so the browser starts the fetch immediately and prioritizes the response. class (optional) */ -}} {{- $src := .src -}} {{- $alt := default "" .alt -}} {{- $width := default 800 .width -}} {{- $height := default 0 .height -}} {{- $quality := default 82 .quality -}} {{- $priority := default false .priority -}} {{- $loading := default (cond $priority "eager" "lazy") .loading -}} {{- $class := default "" .class -}} {{- $r := resources.Get $src -}} {{- if $r -}} {{- if eq $r.MediaType.SubType "svg" -}} {{- else -}} {{- $resized := $r.Resize (printf "%dx webp q%d" $width $quality) -}} {{- $srcset := "" -}} {{- if ge $r.Width (mul $width 2) -}} {{- $resized2x := $r.Resize (printf "%dx webp q%d" (mul $width 2) $quality) -}} {{- $srcset = printf "%s 1x, %s 2x" $resized.RelPermalink $resized2x.RelPermalink -}} {{- end -}} {{- end -}} {{- else -}} {{- end -}}
