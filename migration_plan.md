Project Objective: To redesign and develop a modern, professional, and engaging startup-style website for "PediaMedAI". The project involves transforming an existing academic website into a dynamic marketing and information hub. All design and content specifications are detailed below, as you will not have direct access to any URLs.

Part 1: General Aesthetics & Feel (Inspired by Figma Website Example)

This section defines the overall visual language of the website.

1.1. Color Palette:

Background: Pure White (#FFFFFF).

Primary Text: Very Dark Gray / Off-Black (#212121).

Secondary Text/Subtitles: Medium Gray (#6F6F6F).

Accent Color: A bright, trustworthy blue for buttons, links, and highlights (#0078FF).

Subtle Background/Dividers: Very Light Gray (#E9E9E9).

1.2. Typography:

Headings Font (H1, H2, H3): A serif font with a classic, authoritative feel. "Crimson Text" is a perfect example. Headings should be large and impactful.

Body & Navigation Font: A clean, modern sans-serif font like "DM Sans" or "Inter". Text should be highly readable with ample line spacing (approx. 1.5x font size).

Font Sizing Example:

H1 (Main Page Title): 60px, bold.

H2 (Section Titles): 40px, bold.

Body Text: 16px, regular weight.

Navigation Links: 15px, medium weight.

1.3. Layout & Spacing:

The design must be clean, uncluttered, and spacious.

Utilize a 12-column grid system with a maximum content width of 1200px.

Incorporate generous "white space" (negative space) around all elements and sections to improve readability and focus.

Standard padding for sections should be 80px on the top and bottom.

1.4. Animations & Transitions:

Scroll Animation: As the user scrolls, new content sections should appear smoothly. Implement a "fade-in and slide-up" effect for incoming elements. The animation should be subtle, with a vertical translation of about 20px and an opacity change from 0 to 1.

Hover Effects: Buttons and links should have a subtle transition effect on hover, such as a slight lift (box-shadow) or a background color fade-in.

Logo: "PediaMedAI" text logo on the far left.

Links (Right-aligned): Home, Team, Research, Publications, Workshops.

Style: White background with a subtle drop shadow when scrolling.
