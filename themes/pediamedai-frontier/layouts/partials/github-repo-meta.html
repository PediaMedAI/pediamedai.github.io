{{- /* GitHub repo metadata — fetched at build time via the GitHub API. Renders nothing on any failure (network down, rate-limited, repo missing, malformed JSON) so a flaky API never breaks the build. Hugo's resources.GetRemote caches responses (default 30 min) so multiple builds in quick succession don't refetch. Uses Hugo's `try` keyword (introduced in 0.141.0) to capture errors from GetRemote and Unmarshal — Resource.Err was removed in 0.141.0 in favor of this pattern. Args: repo (required) e.g. "PediaMedAI/AggPose" Output: a sequence of plain spans separated by aria-hidden middot spans. Styling is inherited from .card-meta on the wrapping element. */ -}} {{- $url := printf "https://api.github.com/repos/%s" .repo -}} {{- $r := try (resources.GetRemote $url) -}} {{- with $r.Value -}} {{- $parsed := try (transform.Unmarshal .) -}} {{- with $parsed.Value -}} {{- $stars := .stargazers_count | default 0 -}} {{- $lang := .language | default "" -}} {{- $pushed := .pushed_at | default "" -}} ★ {{ $stars }} {{- with $lang }} · {{ . }}{{ end -}} {{- if $pushed -}} {{- $t := time $pushed -}} · Updated {{ $t.Format "Jan 2, 2006" }} {{- end -}} {{- end -}} {{- end -}}
