# CV4CHL background image for homepage

The CVPR 2026 workshop card on the main page uses an image at:

**`cv4chl_bg.jpg`** (this folder)

To use the same background as https://pediamedai.com/cv4chl/:

1. Open https://pediamedai.com/cv4chl/ and locate the hero/background image (e.g. right-click the top section → "Inspect" → find the `img` or `background-image` URL).
2. Download that image and save it here as **`cv4chl_bg.jpg`**.
3. Rebuild or refresh the site. The CVPR card will show the image; if the file is missing, a placeholder icon is shown instead.
